# Demo video script — #BuildHybridAI / HybridNotes
Screen-recorded only, nobody on camera (passes the video-free gate). Target ≤2:45 (limit 3:00). Record at submission time against the hosted demo in Chrome. Narration: TTS or captions — no human voice required; English subtitles burned in.

## Shot list
1. **0:00–0:15 — Title + problem.** Title card: "HybridNotes — the right model for every note." Caption: "Short notes deserve on-device privacy and speed. Long documents deserve cloud quality. HybridNotes routes each one automatically with Firebase AI Logic."
2. **0:15–0:50 — Short note, on-device.** Paste a short note (grocery list / meeting reminder). Click Summarize. Show the result card + the route badge reading ON-DEVICE (PREFER_ON_DEVICE). Caption: "Short input → on-device model. Fast, private, works offline."
3. **0:50–1:35 — Long document, cloud.** Paste a long document (multi-paragraph article). Click Summarize. Show route badge reading CLOUD (ONLY_CLOUD) and the summary. Caption: "Long input → cloud model via Firebase AI Logic for higher-quality summaries."
4. **1:35–2:10 — Fallback.** Toggle the demo's backend-off switch (or block network) and summarize again. Show the automatic fallback badge and the local extractive summary. Caption: "If the preferred backend is unavailable, HybridNotes falls back automatically — the user always gets a result."
5. **2:10–2:45 — Close.** Show the routing summary panel (three routes, one app) + repo/demo links on an end card. Caption: "HybridNotes — hybrid inference with Firebase AI Logic + App Check. Built for #BuildHybridAI."

## Capture notes
- Chrome window, hosted demo URL visible in the address bar at least once (proves the live demo).
- Mouse movements slow and deliberate; pause 1s on each route badge so judges can read it.
- Export 1080p MP4, upload public to YouTube, paste the link into DEVPOST-DRAFT.md at submission.
